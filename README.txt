شعر و تال غفور — نسخه HTML برای GitHub Pages

محتویات:
- index.html : برنامه اصلی
- profile.jpg : عکس داخل برنامه
- app-icon.png : آیکن سرمه‌ای و طلایی

راه‌اندازی:
1) ZIP را از حالت فشرده خارج کنید.
2) هر سه فایل را یکجا در ریشه Repository گیت‌هاب آپلود کنید (نه خود فایل ZIP).
3) در Settings > Pages، گزینه Deploy from a branch، شاخه main و پوشه /(root) را انتخاب کنید.
4) لینک GitHub Pages را در Safari آیفون باز کنید و Share > Add to Home Screen را بزنید.

نکته: فایل‌های رسانه‌ای که از داخل برنامه اضافه می‌کنید در حافظه مرورگر همین دستگاه ذخیره می‌شوند و به گیت‌هاب آپلود نمی‌شوند. پاک‌کردن داده‌های Safari ممکن است آن‌ها را پاک کند. برای پخش پس‌زمینه، iOS ممکن است هنگام قفل صفحه محدودیت داشته باشد.
